## 구현 현황

로컬 MVP를 구현했고 통합 검증을 진행 중이다. 프로필, 통합 캘린더·마감순 목록, 일정 수정·완료·삭제, 준비물 체크리스트, 알림 설정·발송 기록을 서버의 SQLite에 저장한다. 장학금 3개·채용 3개는 **샘플 공고**이며, 프로필과 공고의 명시된 조건을 규칙으로 비교한다. 실시간 공고 수집이나 AI 순위 추천은 구현 범위에 포함하지 않는다.

사용자가 붙여넣은 공지 분석과 취업 컨설팅은 Anthropic API 키가 필요하다. API 키 없이 제공하는 샘플 결과는 미리 준비한 결과다. 격리된 임시 데이터베이스와 모의 API 응답으로 저장·알림·AI 응답 검증을 수행했으며, 실제 Anthropic 호출과 실제 텔레그램 자격증명을 이용한 외부 발송은 검증하지 않았다. 현재 버전은 인증 없는 로컬 단일 사용자용이다.

## 로컬 실행

Node.js 22 이상에서 실행한다.

```sh
npm install
npm run dev
```

기본 주소는 `http://localhost:3000`이다. `npm run dev`는 웹 서버와 예약 알림 프로세스를 함께 실행한다. 일정·프로필·알림 기록은 기본적으로 `data/campus.db`에 저장된다.

### AI 분석

`.env.local`에 `ANTHROPIC_API_KEY`를 설정하면 사용자 공지 분석과 취업 컨설팅을 실행할 수 있다. 모델은 `ANTHROPIC_MODEL`로 지정하며 기본값은 `claude-sonnet-4-6`이다. 전체 설정 항목은 [.env.example](.env.example)을 참고한다.

API 키가 없어도 명시된 샘플 공고·과제·컨설팅으로 흐름을 확인할 수 있다. 샘플과 실제 AI 결과를 구분하고, 사용자 텍스트의 분석 실패를 샘플 결과로 대체하지 않는다.

### 텔레그램 알림

1. [BotFather](https://t.me/BotFather)에서 봇을 만들고 토큰을 발급받는다.
2. 수신할 채팅에서 해당 봇을 시작하고 채팅 ID를 확인한다.
3. 앱의 설정 화면에서 봇 토큰·채팅 ID를 입력하고 텔레그램 알림을 활성화한다.
4. 테스트 발송을 확인한 뒤 실제 일정에 텔레그램 알림 시각을 설정한다.

환경변수 `TELEGRAM_BOT_TOKEN`과 `TELEGRAM_CHAT_ID`로도 초기 설정을 제공할 수 있다. 토큰은 서버에만 저장하고 상태 조회에 포함하지 않는다. 발송은 [Telegram Bot API](https://core.telegram.org/bots/api#sendmessage)를 사용한다.

브라우저를 닫아도 서버 알림 프로세스가 실행 중이면 텔레그램 예약을 처리한다. 컴퓨터나 서버가 꺼져 있으면 정시 발송할 수 없다. 샘플 일정은 텔레그램에 자동 발송하지 않는다.

### 준비물 체크리스트

일정 상세에서 준비물을 추가·수정·삭제하고 준비 완료 여부를 체크할 수 있다. 장학금·채용 공고나 AI 분석 결과에서 일정을 등록하면 제출 서류를 체크리스트 초안으로 가져온다. 취업 컨설팅의 **준비 계획 한 번에 등록**을 누르면 준비할 일을 하나의 일정에 모을 수 있다. 내용을 확인한 뒤 **일정 저장**을 누르면 저장되며, 새로고침 후에도 복원된다.

일정 목록에 준비한 항목 수가 표시된다. 체크리스트만 수정하면 기존 알림 예약과 발송 기록을 유지한다. 모든 준비물을 체크해도 지원·제출 완료로 자동 처리하지 않으며, 실제 제출 후 일정을 따로 완료 처리한다. 일정당 최대 50개, 항목당 200자까지 입력할 수 있다.

### 검증과 운영

```sh
npm run typecheck
npm test
npm run build
npm run test:e2e
```

`npm start`는 빌드된 웹 서버와 알림 프로세스를 함께 실행한다. 이 버전은 로컬 단일 사용자용이며 웹 서버는 기본적으로 `127.0.0.1`에 연결한다. 운영 환경에서는 사용자 인증과 데이터 분리, 지속 실행할 알림 프로세스가 필요하다. 서버리스 배포 시 예약 발송은 별도 worker 또는 cron 구성이 필요하다.

## 주제 정리

**한 줄 정의**: 학생 개인에게 맞는 장학금과 채용 정보를 찾아주고, 취업 준비를 도우며, 과제와 지원 마감을 하나의 캘린더에 모아 알림으로 챙겨주는 서비스

### 핵심 기능

| 기능 | AI가 도와주는 일 | 캘린더·알림 연결 |
|---|---|---|
| 장학금 | 학년·전공·학점 등 학생 프로필과 공고 조건을 비교해 장학금 추천, 지원 조건과 제출 서류 정리 | 신청 마감과 서류 준비 일정 알림 |
| 개인 맞춤 취업 정보 | 관심 직무·전공·경력에 맞는 채용·인턴 공고 추천, 자격 조건과 추천 이유 정리 | 지원 마감과 확정된 면접 일정 알림 |
| 취업 컨설팅 | 목표 공고에 맞춘 이력서·자기소개서 피드백, 면접 예상 질문과 준비 계획 제안 | 사용자가 확인한 취업 준비 일정 알림 |
| 과제 마감일 캘린더 | eCampus·구글 클래스룸·카톡 공지의 텍스트나 스크린샷에서 과목·과제·마감 추출 | 과제 제출 마감 알림 |

**알림은 네 기능에 공통으로 적용**: D-3, D-1, 당일 알림을 기본으로 제안하고 사용자가 알림 시각과 수신 여부를 설정. 준비·지원·제출 완료 항목은 이후 알림을 중지.

알림 채널은 앱 내·브라우저·텔레그램으로 구성하며, 텔레그램은 서버 예약 발송을 사용한다.

### 왜 이 주제인가

1. **팀이 겪는 문제에서 출발**: 과제 마감, 장학금, 취업 정보처럼 브레인스토밍에서 나온 불편을 학생 한 명의 생활 흐름으로 연결
2. **정보 확인부터 행동까지 연결**: 공고를 추천하는 데서 끝나지 않고 준비할 일과 마감을 캘린더·알림으로 관리
3. **개인별로 필요한 정보가 다름**: 학년·전공·관심 직무에 따라 추천하고, 취업 서류에 대한 피드백도 개인 상황에 맞춰 제공
4. **AI의 역할이 분명함**: 비정형 공지에서 조건과 마감을 추출하고, 학생 프로필과 비교하며, 취업 준비에 필요한 피드백을 생성
5. **공통 흐름으로 시연 가능**: 샘플 공지와 프로필 입력 → 맞춤 추천·피드백 → 일정 확인 → 캘린더 등록 → 알림으로 하루 MVP 구성
6. **도입을 제안할 대상이 분명함**: 학생에게 무료로 제공하고 학교 사업단·장학팀·취업지원센터·교수학습지원센터에 도입을 제안. 실제 구매 의향과 예산은 인터뷰로 검증

### 누구의 어떤 귀찮음인가

- 대상: 수업을 들으며 장학금 신청과 취업 준비를 병행하는 대학생
- 장학금·채용·수업 공지가 학교 홈페이지, 채용 사이트, eCampus, 카톡방에 흩어져 있음
- 공고마다 지원 조건을 읽고 자신에게 해당하는지 판단해야 함
- 이력서·자기소개서를 목표 직무에 맞게 고치고 면접 준비 계획도 세워야 함
- 장학금 신청, 채용 지원, 과제 제출 마감을 각각 기록하고 기억해야 함

### AI가 무엇을 대신해 주나

1. **입력**: 학생 프로필, 장학금·채용·과제 공지, 취업 서류를 입력받음. MVP는 텍스트 붙여넣기와 샘플 데이터 중심으로 구성
2. **추출**: 공지에서 지원 조건, 제출 서류, 과제명, 마감일시, 제출 방법을 구조화하고 원문을 함께 표시
3. **맞춤 추천·컨설팅**: 장학금과 채용 공고를 프로필과 비교해 추천 이유를 설명하고, 목표 채용 공고에 맞춰 취업 서류 피드백과 준비 계획을 제안
4. **확인·통합**: 사용자가 추출 결과와 준비 일정을 확인·수정한 뒤 장학금·취업·과제 일정을 하나의 캘린더와 마감순 목록에 등록
5. **알림**: 각 일정에 설정한 시각에 알림을 보내고, 완료 여부를 반영해 남은 일정을 관리

상대 날짜는 공지 작성일, 수업 시간은 시간표를 기준으로 해석. 작성일·수업 시간·지원 조건이 부족하면 확인 필요로 표시하고 사용자가 확정. 공지에 없는 면접 일시나 마감은 임의로 만들지 않음.

### 누가 얼마를 낼까

- **학생**: 무료로 사용
- **학교 사업단·장학팀·취업지원센터·교수학습지원센터**: 학교 단위 도입료 연 1,000만 원 안팎을 제안하는 가설. 실제 가격, 사업 예산 활용 가능 여부, 정보 제공·LMS 연동 조건은 담당자 인터뷰로 검증

### 차별점

- **장학금·취업 정보·취업 컨설팅·과제 관리가 학생 프로필과 하나의 캘린더로 연결**
- 공지 입력 → 나에게 맞는 정보와 준비할 일 정리 → 마감 등록 → 알림까지 이어지는 흐름
- 공지에서 조건과 마감을 추출해 일정 입력 부담을 줄이고, 확인이 필요한 정보는 따로 표시

체크한 항목은 기능 구현 상태이며, 실제 외부 서비스 연동이나 모든 검수 시나리오의 통과를 뜻하지 않는다.

MVP의 브라우저 알림은 사용자의 알림 권한 허용과 페이지 실행을 전제로 시연하고, 권한을 허용하지 않으면 앱 내 알림으로 표시. 페이지를 닫아도 전달되는 푸시 알림, 학교·채용 사이트 자동 연동, 중복 일정 병합은 후속 범위로 둠.

### 데모 시나리오

1. 학생 프로필 입력 → 샘플 공고에서 나에게 맞는 장학금과 채용 공고 추천
2. 관심 채용 공고와 자기소개서 입력 → 피드백·면접 질문·준비 계획 확인
3. 카톡 과제 공지 붙여넣기 → 과제와 마감 추출 → 확인·수정
4. 장학금 신청, 채용 지원, 취업 준비, 과제 제출 일정을 하나의 캘린더에 등록
5. 데모용 일정의 알림을 1분 뒤로 설정 → 실제 알림 수신 → 완료 처리
