# 국민대 데이터 연동 안내

국민대학교 학사일정·공지사항과 eCampus(가상대학) 과제 마감을 캠퍼스 비서의 일정으로 가져오는 방법입니다.
앱은 학교 계정으로 로그인하지 않으며, 아이디와 비밀번호를 묻지도 저장하지도 않습니다.

## 1. 학사일정 가져오기

1. 앱의 국민대 연동 화면에서 **학사일정**을 엽니다.
2. 현재 학년도의 일정(개강, 수강신청 변경, 중간·기말시험, 등록 기간 등)이 목록으로 나옵니다.
3. 필요한 일정을 골라 **가져오기**를 누르면 `학사 일정` 종류로 저장됩니다.

- 원본: <https://www.kookmin.ac.kr/user/scGuid/scSchedule/index.do>
- 학교 페이지에는 `03.03 (화) ~ 03.09 (월)`처럼 연도가 없습니다. 3~12월은 해당 학년도, 1~2월은 다음 해로 계산합니다(2026학년도의 2월 → 2027년 2월).
- 기간 일정은 시작일과 종료일이 함께 표시됩니다. 일정으로 저장할 날짜는 화면에서 고른 값이 쓰입니다.
- 서버가 10분 동안 결과를 기억합니다. 학교 사이트가 잠시 응답하지 않으면 마지막으로 읽은 내용을 보여 주고, 읽은 적이 없으면 "국민대 학사일정을 불러오지 못했습니다. 잠시 후 다시 시도해 주세요."라고 알립니다.

## 2. 공지사항 가져오기

1. **공지** 탭에서 게시판(학사공지 / 장학공지 / 일반공지)을 고릅니다.
2. 글을 누르면 본문을 읽어 옵니다. 본문에서 마감일을 확인한 뒤 일정으로 저장할 수 있습니다.
3. **더 보기**로 다음 쪽을 불러옵니다.

- 원본: 학사 `/user/kmuNews/notice/4/index.do`, 장학 `/user/kmuNews/notice/7/index.do`, 일반(전체) `/user/kmuNews/notice/index.do`
- 상단 고정 글은 학교 목록에 작성일이 없어 날짜가 비어 있습니다. 글을 열면 작성일이 채워집니다.
- 공지의 "작성일"은 마감일이 아닙니다. 마감은 본문을 읽고 직접 확인해 주세요.
- 본문은 글자만 가져옵니다(최대 20,000자). 이미지·첨부파일 안의 내용은 가져오지 못하므로 원문 링크에서 확인해야 합니다.
- 포스터 이미지 한 장만 올린 공지는 본문이 빈 값으로 옵니다(특강·행사 공지에 많습니다). 이런 글은 원문을 열어 날짜를 직접 확인해 주세요.
- 목록과 본문은 5분 동안 기억합니다.

## 3. eCampus 과제 가져오기 — 달력 URL(ICS)

eCampus(<https://ecampus.kookmin.ac.kr>)는 학교 통합 로그인 뒤에 있어 앱이 직접 들어갈 수 없습니다.
대신 eCampus가 제공하는 **달력 내보내기 URL**을 사용합니다.

### URL 만드는 법

1. eCampus에 로그인합니다.
2. **달력(캘린더)** 화면으로 갑니다. 대시보드의 달력 블록에서 달 이름을 누르거나 주소창에 `https://ecampus.kookmin.ac.kr/calendar/view.php`를 입력합니다.
3. 달력 아래의 **달력 내보내기**(Export calendar)를 누릅니다.
4. 내보낼 일정은 **모든 일정**, 기간은 **최근 및 다음 60일**을 고릅니다.
5. **달력 URL 가져오기**(Get calendar URL)를 누르면 아래와 같은 주소가 나옵니다.

   ```
   https://ecampus.kookmin.ac.kr/calendar/export_execute.php?userid=…&authtoken=…&preset_what=all&preset_time=recentupcoming
   ```

6. 이 주소를 앱의 **eCampus 달력 URL** 칸에 붙여 넣고 **미리 보기**를 누릅니다.
7. 가져올 과제를 골라 **가져오기**를 누릅니다.

URL을 만들기 어렵다면 같은 화면의 **내보내기** 버튼으로 `.ics` 파일을 받아, 파일 내용을 **ICS 붙여 넣기** 칸에 넣어도 됩니다.

### 알아 둘 점

- 이 URL에는 본인만 아는 토큰(`authtoken`)이 들어 있습니다. **비밀번호처럼 다루고** 다른 사람에게 보내거나 공개된 곳에 올리지 마세요. 이 주소를 아는 사람은 로그인 없이 내 eCampus 일정을 읽을 수 있습니다.
- 유출이 걱정되면 비밀번호를 바꿔 보세요. Moodle 표준 동작으로는 비밀번호가 바뀌면 기존 URL이 무효가 되지만, 국민대는 통합 로그인을 쓰므로 실제로 무효가 되는지는 확인하지 못했습니다. 확실하지 않으면 학교 eCampus 담당 부서에 문의하세요.
- 앱은 URL을 **저장하지 않고 로그에도 남기지 않습니다.** 미리 보기를 누를 때 한 번만 사용하므로, 과제가 새로 생기면 URL을 다시 붙여 넣어야 합니다.
- 서버는 `https://ecampus.kookmin.ac.kr/calendar/export_execute.php`로 시작하는 주소만 읽습니다. 다른 주소는 "국민대 eCampus 달력 내보내기 주소가 아닙니다"라고 거절합니다.
- "가져오지 못했습니다. 로그인이 필요하거나 만료된 링크일 수 있습니다"가 나오면 eCampus에서 URL을 다시 만들어 주세요.
- 마감 시각은 한국 시각으로 바꿔 저장합니다. 제목 끝의 `is due`, `마감`, `제출 마감` 같은 말은 지웁니다. 과목명은 달력의 분류(CATEGORIES) 값에서 읽습니다.
- 이미 가져온 과제는 다시 가져와도 중복으로 저장되지 않습니다(건너뜀으로 표시).

## 4. eCampus 과제 가져오기 — 북마클릿

달력 URL을 만들지 않고, eCampus 화면에서 버튼 하나로 다가오는 마감을 앱으로 보내는 방법입니다.

### 설치와 사용

1. 앱의 eCampus 연동 화면에서 **북마클릿** 버튼을 브라우저 북마크바로 끌어다 놓습니다. 끌어다 놓기가 안 되면 **코드 복사**를 누른 뒤 새 북마크를 만들어 주소 칸에 `javascript:`와 함께 붙여 넣습니다.
2. eCampus에 로그인한 뒤 대시보드나 달력 화면에서 북마크를 누릅니다.
3. 새 탭으로 앱이 열리고 가져온 과제 목록이 나옵니다. 고른 뒤 **가져오기**를 누릅니다.

### 동작 방식

- 북마클릿은 eCampus 화면 안에서 실행되어, eCampus가 대시보드에 마감 목록을 그릴 때 쓰는 것과 같은 요청(`core_calendar_get_action_events_by_timesort`)으로 앞으로의 마감 최대 50개를 읽습니다. 실패하면 "다가오는 일정" 화면에 보이는 항목을 읽습니다.
- 읽은 과제 제목·과목·마감·링크만 앱 주소의 `#kmu-import=…` 뒤에 담아 앱을 엽니다. `#` 뒤의 값은 서버로 전송되지 않고 브라우저 안에서만 읽힙니다.
- 아이디, 비밀번호, 로그인 세션 값은 앱으로 보내지 않습니다. 외부 스크립트도 불러오지 않습니다.

### 알아 둘 점

- 북마클릿에는 앱 주소가 들어 있습니다. 앱 주소가 바뀌면(예: 로컬 → 배포 주소) 북마클릿을 다시 설치해야 합니다. 배포 환경에서는 `APP_URL` 값이 쓰입니다.
- 팝업이 차단되면 현재 탭이 앱으로 이동합니다. 새 탭으로 열고 싶으면 eCampus 사이트의 팝업을 허용해 주세요.
- eCampus가 아닌 사이트에서 누르면 안내만 띄우고 아무것도 하지 않습니다. 로그인이 풀린 상태에서 누르면 로그인하라는 안내가 나옵니다.
- 모바일 브라우저는 북마클릿 실행이 막혀 있는 경우가 많습니다. 모바일에서는 달력 URL 방식을 쓰세요.
- 과제가 아주 많으면 주소 길이 제한 때문에 먼 마감부터 빠질 수 있습니다.

## 5. 한계와 주의

- 학교 홈페이지의 화면 구조를 읽는 방식이라, 학교가 페이지를 개편하면 한동안 동작하지 않을 수 있습니다.
- 가져온 내용은 가져온 시점의 사본입니다. 일정이나 마감이 바뀌어도 앱의 일정은 자동으로 바뀌지 않습니다. 중요한 일정은 원문을 다시 확인하세요.
- 가져올 때 이미 지난 알림이나 마감 뒤로 잡힌 알림은 자동으로 빠집니다.
- 한 번에 최대 200개까지 가져옵니다. 날짜가 잘못된 항목은 그 항목만 실패로 표시되고 나머지는 저장됩니다.
- 학교 서버에 부담을 주지 않도록 학사일정 10분, 공지 5분 동안 같은 요청을 다시 보내지 않습니다.
- 성적, 출석, 강의 자료, 수강 과목 목록은 가져오지 않습니다.

## 6. 확인한 것과 가정한 것 (2026-10-03 기준)

### 실제 사이트에서 확인

- 학사일정 페이지는 로그인 없이 GET으로 열리고 `Content-Type: text/html;charset=utf-8`입니다. 한 학년도 전체(60건)가 `table#monthTable`에 들어 있고, 행은 `월 / 03.03 (화) ~ 03.09 (월) / td.cal_desc` 구조입니다. 학년도는 `p.accd_head`의 `<em>2026</em>학년도`에서 읽습니다. 다음 해 1~2월 행은 월 칸에 `2027년`이 함께 적혀 있습니다.
- 공지 목록(학사 4, 장학 7, 일반)은 로그인 없이 열리고 UTF-8입니다. 한 쪽에 20건이며 `?currentPageNo=2`로 다음 쪽이 열립니다(1쪽과 다른 글이 나오는 것을 확인). 전체 쪽수는 `페이지 1 / 41` 표시에서 읽습니다.
- 상단 고정 글(`li.notice`)에는 작성일이 없고, 일반 글은 `div.board_etc`의 첫 칸에 `2026.10.03` 형식으로 있습니다.
- 일반공지 목록의 글은 각자 원래 게시판 번호(4, 6, 7, 9, 10, 14 …)가 붙은 주소를 가집니다. 상세 페이지는 주소의 게시판 번호와 상관없이 글 번호로 열립니다.
- 공지 상세는 `p.view_tit`(제목), `작성일 2026.10.03`, `div.view_inner`(본문) 구조입니다. 없는 글 번호도 200으로 응답하지만 본문 영역이 없어 앱은 404로 처리합니다.
- 학사일정 페이지는 `?yyyy=2025`, `?yyyy=2027`처럼 `yyyy` 값으로 다른 학년도를 보여 줍니다(각각 48건, 45건으로 다른 표가 나오는 것을 확인). 앱은 항상 `yyyy`를 붙여 요청합니다.
- 공지 목록에서 `pageIndex=2`는 무시되고 1쪽이 그대로 나옵니다. 쪽 번호 파라미터는 `currentPageNo`입니다. 전체 쪽수를 넘는 번호(예: 41쪽까지인 게시판의 400쪽)를 요청하면 빈 목록이 옵니다.
- 본문이 이미지 한 장뿐인 공지(일반공지의 특강 안내)는 본문 텍스트가 빈 값으로 읽힙니다.
- 실제 route 핸들러로 다음을 읽어 확인했습니다: 학사일정(60건, 3월 3일 개강 ~ 2027년 2월 등록 기간, 해를 넘기는 "동계 계절학기 수업 기간 2026-12-22 ~ 2027-01-13" 포함), 학사공지 1·2·41쪽, 장학공지 1쪽, 일반공지 1쪽, 학사공지 글 1건과 일반공지 글 1건의 본문, 없는 글 번호(404).
- eCampus(로그인 없이 확인한 범위): `https://ecampus.kookmin.ac.kr/calendar/export_execute.php`에 틀린 토큰을 보내면 **HTTP 200**과 함께 `Invalid authentication`이라는 글자만 옵니다. 그래서 앱은 상태 코드가 아니라 내용이 `BEGIN:VCALENDAR`로 시작하는지로 성공 여부를 판단합니다.
- eCampus는 Moodle 3.9입니다(오류 응답의 도움말 주소가 `docs.moodle.org/39/ko`). 로그인 화면은 코스모스(coursemos) 테마이고 `M.cfg`를 씁니다.
- 로그인하지 않은 상태에서도 화면에 `M.cfg.sesskey`가 있습니다. 이 상태로 `/lib/ajax/service.php`의 `core_calendar_get_action_events_by_timesort`를 부르면 `[{"error":true,"exception":{"errorcode":"servicerequireslogin", …}}]`가 옵니다. `/calendar/view.php?view=upcoming`과 `/calendar/export.php`는 로그인 화면으로 303 이동합니다. 그래서 북마클릿은 두 경우 모두 "eCampus에 로그인한 뒤 다시 실행해 주세요"라고 안내합니다.

### 가정 (실제 계정으로 확인하지 못함)

- eCampus에는 로그인하지 않았습니다. 실제 계정으로 만든 달력 내보내기 URL과 그 ICS 내용(`SUMMARY: … is due`, `CATEGORIES`에 과목명, UTC 시각)은 Moodle의 일반 동작을 근거로 한 것입니다.
- eCampus 메뉴 이름(달력 내보내기, 달력 URL 가져오기)과 선택 항목 이름은 Moodle 한국어 화면 기준이며 학교 설정에 따라 조금 다를 수 있습니다.
- 한국어 화면에서 과제 제목 뒤에 붙는 말(`마감`, `제출 마감` 등)은 추정입니다. 다른 표현이면 제목에 그대로 남습니다.
- 북마클릿이 쓰는 `core_calendar_get_action_events_by_timesort`의 **로그인 후** 응답 모양(`data.events[].name/timesort/course/action`)과, 화면에서 읽는 대체 경로의 선택자는 Moodle 3.9 표준 기준입니다. 서비스가 존재하고 로그아웃 상태에서 어떻게 응답하는지만 실제로 확인했습니다.
- 북마클릿은 브라우저를 흉내 낸 테스트 환경에서만 실행해 보았습니다(`tests/kookmin.test.ts`). 로그인한 국민대 eCampus 화면의 실제 브라우저에서는 실행해 보지 못했으므로, 처음 쓸 때 가져온 과제의 제목·마감 시각이 eCampus 화면과 같은지 꼭 확인해 주세요.
- 자동 테스트는 위 구조를 줄여 옮긴 예시 파일(`tests/fixtures/`)로 돌립니다. ICS 예시는 직접 만든 것입니다.

## 7. 개발자용 요약

| 경로 | 설명 |
| --- | --- |
| `GET /api/kookmin/schedule` | `{ items, year, fetchedAt, cached }`. `?year=2027`로 학년도를 고를 수 있고, 없으면 서울 기준 현재 학년도 |
| `GET /api/kookmin/notices?board=academic\|scholarship\|general&page=1` | `{ items, board, page, hasMore, fetchedAt }` |
| `GET /api/kookmin/notices/[board]/[articleNo]` | `{ item }` (본문 포함) |
| `POST /api/kookmin/ecampus/preview` | `{ url }` 또는 `{ ics }` → `{ items, calendarName, fetchedAt }` |
| `POST /api/kookmin/import` | `{ items }`(1~200개) → `{ created, skipped, failed, state }` |
| `GET /api/kookmin/bookmarklet` | `{ href, code }` |

- 코드는 `lib/kookmin/`(http, text, schedule, notices, ics, ecampus, bookmarklet, mapping)에 있고, 저장은 `lib/store.ts`의 `importEvents`가 맡습니다.
- 테스트: `node --import tsx --test tests/kookmin.test.ts`
